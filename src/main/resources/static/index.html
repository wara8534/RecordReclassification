    기록물 검토

    PDF·이미지·녹음·영상 최대 20개, 파일당 25MB, 기록물당 총 100MB

    영상은 음성을 전사하므로 판단에 필요한 화면 정보는 별도 문서로 포함해 주세요.

    ‘검토필요’ 상태에서는 검토 완료로 저장할 수 없습니다.

    작업 안내

    1. 등록 서식을 작성하세요

      기록물철·기록물건 시트의 이름과 순서, 상단 4행을 유지하세요. 5행부터 제목과 비고 또는 주요내용을 입력하세요.

    2. 분류 결과를 확인하세요

      결과 목록에서 기존 공개구분과 재분류 결과를 확인하세요. 내용이 비어 있으면 검토필요로 표시됩니다.

    3. 검토필요 건을 확인하세요

      검토 화면에서 공개구분과 사유를 수정하세요. 비공개호수와 부분공개의 공개제한부분도 입력할 수 있습니다. 검토 완료 항목은 다시 분류할 때 유지됩니다.

    4. 결과 엑셀을 내려받으세요

      등록 서식의 공개구분·비공개호수·공개제한부분·비공개사유에 결과를 기록합니다. 검토필요 건의 공개 관련 값은 원본대로 보존합니다.

    현재 버전은 단일 사용자 로컬 작업용입니다. 새로고침하거나 창을 닫으면 작업 데이터가 사라집니다. 분류 기준은 서버에 고정되어 유지됩니다. 업로드는 10MB 이하, 기록물은 최대 200,000건입니다. 수식은 값으로 변환해 주세요.

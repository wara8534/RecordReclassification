    작업 안내

    1. 첨부 서식을 사용하세요

      ‘입력 양식 다운로드’는 제공하신 서식.xlsx입니다. 15개 열 이름을 유지하고 앞의 12개 열을 작성하세요. 기록물제목은 필수이며 내용이 비어 있으면 검토필요로 분류합니다.

    2. 분류 결과를 확인하세요

      업로드하면 제목·기록물분류·내용·키워드를 분석해 공개여부·비공개사유·판단근거를 화면에 표시합니다. 업로드하거나 다시 분류해도 자동 다운로드하지 않습니다. ‘결과 다운로드’를 눌렀을 때 엑셀 파일을 생성해 내려받습니다.

    3. 필요하면 수정하세요

      각 행의 ‘검토’에서 세 결과 값을 수정한 후 다운로드할 수 있습니다. 검토 완료 항목은 ‘다시 분류’ 시 유지됩니다. 공개로 변경하면 비공개사유는 비웁니다.

    4. 원본을 보존합니다

      첫 번째 시트의 입력 값·추가 열·다른 시트는 보존하고 세 결과 열만 다시 작성합니다. 결과 열의 너비와 데이터 행 높이는 읽기 편하게 조정합니다. 재업로드하면 기존 결과는 새 분류로 대체됩니다. 결과 파일에는 화면의 검토 완료 표시는 별도로 추가하지 않습니다.

    현재 버전은 단일 사용자 로컬 작업용입니다. 새로고침하거나 창을 닫으면 작업 데이터가 사라집니다. 분류 기준은 서버에 고정되어 유지됩니다. 업로드는 10MB / 5,000행 이하, 수식은 값으로 변환해 주세요.
